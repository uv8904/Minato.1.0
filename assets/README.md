# Assets

## plan_qr.png

Ye image `/plan` command ke saath bheji jaati hai (payment / UPI QR).

- File ka naam exactly `plan_qr.png` hona chahiye (PNG/JPG chalega, bas path same rahe).
- Agar aap image ko repo me nahi rakhna chahte to `PLAN_IMG` env var me koi bhi direct image URL (https://...) set kar sakte ho.
- Agar file missing ho aur env var bhi na ho, to bot purani default image use karega.
